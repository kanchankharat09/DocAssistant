SESSION SHEET FOR S10 (timing sessions)
=======================================

Use this sheet while you run the sessions. It says which patient each
role-player gets, so nobody sees the same patient twice in two tasks.
The role-players are called R1, R2 and R3 (labels, not real names).

BEFORE THE FIRST SESSION
  1. python db/seed.py                (a fresh database)
  2. streamlit run app/app.py         (the search page is 'app', the stopwatch is 'Timing')
  3. Delete results/timing.csv if it is there (old practice timings).
  4. Do the sessions in this order: R1, then R2, then R3.
     Why: the approval tasks of one person save a new visit and change that patient's
     card. With this order nobody gets a card that was changed earlier.
  Do NOT run db/seed.py between two sessions.

WHAT YOU SAY (read it aloud, the same words for everyone)
  'You play a doctor. I will say a patient name. Find the last visit and tell me
   four things: the date, the main complaint, the medicines with doses, and the
   follow-up advice. Say DONE when you have told all four. I will time you.'
  For the transcript task: 'The same, but you read this text file instead of the card.'
  For the approval task: 'Review this summary and approve it. Say DONE when you press Approve.'

HOW TO TIME (Timing page)
  Choose the label (R1), the task (card, transcript or approval) and the patient.
  Press Start when you finish saying the patient name. Press Stop when you hear DONE.
  Then say if the answer was correct (compare with the card) and press Save this timing.
  An answer with a missing or wrong detail is 'no'. It is saved, but not counted in the median.
