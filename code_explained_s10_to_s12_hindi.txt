S11: T1 से T5 का final run
==========================
क्यों: plan एक ही run से, final build पर, पाँचों नंबर चाहता है, और उसके बाद कोई बदलाव नहीं।
फ़ाइल: run_tests.py
  run(command)         हमारी एक script चलाकर जो छापे वह लौटाता है
  find_line(...)       उस output में हमें चाहिए वाली line ढूँढता है (रुक गया हो तो error दिखाता है)
  number_after(...)    किसी text के बाद का नंबर लेता है, जैसे "T1 score: 16 of 20" -> 16
  फ़ाइल इस क्रम में चलाती है:
    T1  score_t1.py run2
    T2  check_medicines.py run2 (S6) और app/test_s7.py (S7)
    T3  db/seed.py (नया database) और app/test_s9.py
    T4  results/timing.csv पढ़ता है: सही approval timings का median, 3 लोग चाहिए
    T5  code-mixed cases (T03, T07, T11, T15, T19) में से जो T1 scoring में pass हों: 5 में से 4 चाहिए
  यह एक table छापता है (Pass, Fail या NOT MEASURED), जो git commit जाँचा गया वह दिखाता है,
  uncommitted बदलाव हों तो चेतावनी देता है, और सब results/final_run.txt में save करता है।
कैसे चलाएँ
  पहले सब कुछ commit कीजिए, फिर:  python run_tests.py   (एक बार; इसके बाद कुछ नहीं बदलना)


S12: results note
=================
क्यों: Hitesh और आप एक पन्ने के नापे हुए नंबरों से go, fix या stop तय करते हैं।
फ़ाइल: make_note.py
  read_final_run(file)    results/final_run.txt को T1 से T5 की dictionary में पढ़ता है
  first_number(text)      text का पहला पूरा नंबर
  make_call(tests, speed) GO, FIX, STOP या NO CALL YET कारण के साथ देता है:
      STOP  T1, 20 में से 16 से कम, या T2 फ़ेल, या card, transcript से 2 गुना से कम तेज़
      GO    पाँचों tests pass, card का median 15 s से कम और 2 गुना तेज़
      FIX   बाकी सब (T1 का 16 या 17 "अनिर्णायक: ठीक करो और एक बार फिर चलाओ" है)
      NO CALL YET   जब कुछ नापा नहीं गया हो। यह कभी कोई नंबर नहीं गढ़ता।
  build_note(...)         note की lines बनाता है (tests, speed, फ़ैसला, सीमाएँ)
  main()                  results_note.txt लिखता है और एक पन्ने से लंबा हो तो चेतावनी देता है
कैसे चलाएँ
  python make_note.py     फिर [WRITE ...] वाली दो lines अपने शब्दों में लिखिए
फ़ैसले के नियम step.md की hypothesis से हैं। Hitesh को इस समझ से सहमत होना चाहिए।
